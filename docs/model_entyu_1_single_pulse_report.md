# 円柱電極モデルの単発パルス応答（修正版・2026-10-26）

初期条件と四面体の勾配変換を修正し、円柱モデルを再解析しました。
旧報告書の「OFF後の大きな負電位が物理的に妥当」という結論は撤回します。

r=100の25 ns時点の電位は、旧結果−0.068750 Vに対して修正後 -1.515147e-09 Vです。
端面に残る微小な負電位も、今回の理論条件では空間離散化または残る実装問題を優先して疑うべき結果です。

[修正・9ケースの再解析・比較図を含む報告書](../output/poweroff_20261026/report.md)を参照してください。

2026-10-29：端面に残った微小な負電位は、一次四面体の空間離散化誤差と異方性の組合せが主因と確認しました。[原因究明・Fortran比較の報告書](../output/poweroff_20261029/report.md)を参照してください。
