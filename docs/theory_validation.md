# 円筒電極パルス解析の理論式とFEM比較

## 目的

`models/cylinder_electrode` は、中心円柱電極をパルス電圧で駆動し、外側円筒電極を 0 V 接地した同軸円筒モデルである。

このメモでは、緩和時間

```text
tau = epsilon / sigma
```

を使いながら、まず比較用の理論式を整理し、FEM出力との比較条件を固定する。

この文書には、次の2つのモデルが登場する。数値条件が異なるため、混同しないように注意する。

```text
cylinder_electrode : 理論式を確認するための基準モデル
model_entyu        : 実際に150 stepの解析を行ったモデル
```

前半では `cylinder_electrode` の理想化した同軸円筒を説明し、後半の「`model_entyu` へ適用する際の設定」以降で実メッシュの条件と解析結果を説明する。

## 記号と単位

本文で使用する主な記号を先にまとめる。

| 記号 | 意味 | 単位 |
|---|---|---|
| `a` | 中心電極の外半径。媒質領域の内側境界 | m、mm、またはメッシュ座標単位 |
| `b` | 外側接地電極の内半径。媒質領域の外側境界 | `a`と同じ長さ単位 |
| `r` | 円柱中心軸から評価点までの半径方向距離。`a < r < b` | `a`と同じ長さ単位 |
| `z` | 円柱軸方向の座標 | 長さ |
| `t` | 時刻 | s |
| `phi(r,t)` | 半径`r`、時刻`t`における電位 | V |
| `g(t)` | 中心電極へ与える時間依存の入力電圧 | V |
| `E` | 電場ベクトル | V/m |
| `J` | 導電電流と変位電流を合わせた電流密度 | A/m² |
| `sigma` | 導電率。電流の流れやすさ | S/m |
| `epsilon` | 絶対誘電率。電気的エネルギーの蓄えやすさ | F/m |
| `epsilon_r` | 真空に対する誘電率の比。比誘電率 | 無次元 |
| `epsilon0` | 真空の誘電率 | F/m |
| `tau` | `epsilon/sigma`で定義する電荷緩和時間 | s |
| `alpha(r)` | 電極電圧に対する位置`r`の電位比 | 無次元 |
| `y(t)` | 入力`g(t)`を一次遅れ要素へ通した比較用電圧 | V |
| `dt` | FEMおよび理論離散化の時間刻み | s |
| `nstep` | 計算する時間ステップ数 | 無次元 |

`a`, `b`, `r` は対数の比 `ln(b/r)/ln(b/a)` として現れるため、3つに同じ長さ単位を使えば `alpha(r)` は変わらない。ただし、FEMで電流値まで現実と比較する場合は、メッシュ座標をSI単位のmへ整合させる必要がある。

## 今回使うモデル条件

幾何:

```text
inner electrode radius a = 0.5 mm
outer grounded electrode inner radius b = 4.5 mm
height = 20 mm
comparison plane z = 10 mm
```

境界条件:

```text
phi(a,t) = g(t)
phi(b,t) = 0
```

ここで `phi(a,t)` は中心電極表面の電位、`phi(b,t)` は外側電極内面の電位である。`g(t)` は0 Vと1 Vを切り替えるパルス入力であり、外側電極を電位の基準である0 Vとする。

入力パルス:

```text
period = 50 ns
high = 1 V for 25 ns
low  = 0 V for 25 ns
dt = 1 ns
nstep = 150
```

土壌領域の代表物性:

```text
sigma = 1.0e-2 S/m
epsilon_r = 20
epsilon = epsilon_r * epsilon0 = 1.770838e-10 F/m
tau = epsilon / sigma = 1.770838e-8 s = 17.708 ns
```

`tau` が大きいほど電荷が媒質内に長く残りやすく、`tau` が小さいほど導電によって速く緩和する。ただし、後述するように、理想電圧を電極へ直接強制した場合の内部電位が、必ず `tau` の一次遅れになるわけではない。

土壌物性は含水率・塩分・周波数で大きく変化する。今回は、検証用に「湿り気のある非塩性土壌」程度の仮値として `sigma=0.01 S/m`, `epsilon_r=20` を採用した。

参考として、乾燥土壌の比誘電率はおおむね数程度で、水は約80とされるため、含水土壌ではその中間的な値になる。また、土壌のバルク導電率は含水率や塩分に強く依存し、低含水・非塩性では `0.1 S/m` 未満の値が広く見られる。

## 支配方程式

この節では、FEMが解いている「電位から電場を求め、媒質内で電流が途切れないようにする」という関係を式で表す。

電場と電位の関係を

```text
E = -grad(phi)
```

`grad(phi)` は電位が空間的にどちらへ、どの程度変化するかを表す勾配である。負号が付くため、電場は高電位側から低電位側を向く。

とする。導電電流と変位電流を含めた電流密度は

```text
J = sigma E + epsilon dE/dt
```

右辺第1項 `sigma E` は導電電流密度、第2項 `epsilon dE/dt` は電場の時間変化による変位電流密度である。この解析では両方を加えた `J` の保存を考える。

である。電荷保存から、内部に電流源がない場合は

```text
div(J) = 0
```

`div(J)` は微小領域から出ていく電流と入ってくる電流の差を表す。値が0という条件は、媒質内部に電流源や電流の吸い込みがなく、電荷保存が成立することを意味する。

したがって

```text
div(sigma E + epsilon dE/dt) = 0
```

である。`E = -grad(phi)` を代入すると

```text
div(sigma grad(phi) + epsilon d/dt grad(phi)) = 0
```

一様媒質で `sigma`, `epsilon` が空間的に一定なら

```text
sigma Laplacian(phi) + epsilon d/dt Laplacian(phi) = 0
```

`Laplacian(phi)` は電位の空間的な曲がり具合を表す。均質媒質では、導電率と誘電率がこの空間分布と時間変化に重みを与える。

となる。

この式は、教授との議論で出てきた形

```text
du/dt + (sigma/epsilon) u = f
```

または

```text
du/dt + (1/tau) u = f
```

と対応しており、

```text
tau = epsilon / sigma
```

が電荷緩和時間になる。

ここで `u` は緩和する状態量を一般化して書いた記号であり、この式だけでは必ずしも節点電位 `phi` そのものを意味しない。`f` は境界入力や外部からの励振に対応する一般化した入力項である。この一般的な一次緩和式と、電極電圧を強制した同軸円筒内の電位分布を同一視しないことが重要である。

## 同軸円筒の静的理論解

有限長端部の影響を無視し、中心高さ付近を無限長同軸円筒として近似する。

この近似では、円柱が軸方向に十分長く、電位が周方向や高さ方向へ変化しないと仮定する。したがって、電位は中心軸からの距離 `r` だけで決まる。

円筒対称なので、電位は半径 `r` のみの関数とみなせる。静的なラプラス方程式は

```text
(1/r) d/dr (r dphi/dr) = 0
```

これを積分すると

```text
phi(r) = A ln(r) + B
```

`A`, `B` は積分によって現れる定数で、中心電極と外側電極の電位条件を代入すると決まる。最終式では不要になる。

境界条件

```text
phi(a) = V
phi(b) = 0
```

を入れると

```text
phi(r) = V * ln(b/r) / ln(b/a)
```

したがって、時間依存境界電圧 `g(t)` をそのまま入れた瞬時応答近似は

```text
phi_instant(r,t) = alpha(r) g(t)

alpha(r) = ln(b/r) / ln(b/a)
```

である。

`alpha(r)` は「中心電極電圧の何倍がその位置に現れるか」を表す無次元係数である。中心電極表面 `r=a` では `alpha=1`、外側電極表面 `r=b` では `alpha=0` となり、その間では対数的に減少する。例えば `alpha=0.25` の点では、入力が1 Vなら瞬時理論値は0.25 Vになる。

ここでいう「瞬時」は電磁波が無限速度で伝わるという意味ではない。この準静電モデルの理想化された境界条件の下で、各時刻の電位分布をその時刻の入力 `g(t)` から直接計算する、という比較モデルを意味する。

電場は

```text
E_r(r,t) = -dphi/dr = g(t) / (r ln(b/a))
```

となる。

`E_r` は半径方向の電場成分である。`1/r`に比例するため、同じ入力電圧でも中心電極に近いほど電場が強くなる。

## 一次遅れ近似

ここまでの同軸円筒理論では、中心電極に与えた入力電圧 `g(t)` が、その時刻にそのまま媒質内へ反映されると考えた。

```text
phi_instant(r,t) = alpha(r) g(t)
```

これは「入力が1 Vなら、半径 `r` の電位はすぐ `alpha(r)` Vになる」という比較式である。

一方で、実際の回路や測定では、電圧が急に変わっても内部の応答が少し遅れて立ち上がるように見えることがある。この「入力に対して少し遅れて追いかける」形を、最も単純に表したものが一次遅れである。

一次遅れでは、入力 `g(t)` をそのまま使わず、まず `y(t)` という遅れた電圧を作る。

```text
g(t) : 中心電極に与えた入力電圧
y(t) : g(t) を時定数 tau で遅らせた比較用電圧
```

そして、媒質内の電位を

```text
tau dy/dt + y = g(t)
```

で直接決めるのではなく、まず比較用の遅れた入力 `y(t)` を決める。

この式は次の意味を持つ。

```text
tau dy/dt = g(t) - y(t)
```

右辺の `g(t) - y(t)` は、「入力電圧と、現在の遅れた電圧の差」である。差が大きいほど `y(t)` は速く変化する。差が0になれば、つまり `y(t)=g(t)` になれば、もう変化しない。

`tau` は遅れの大きさを表す時間である。

```text
tau が小さい : y(t) は g(t) にすぐ追いつく
tau が大きい : y(t) は g(t) にゆっくり追いつく
```

例えば、入力が0 Vから1 Vへ急に変わったとする。このとき `y(t)` は瞬間的に1 Vへ飛ばず、指数関数的に1 Vへ近づく。

```text
y(t) = 1 - exp(-t/tau)   # y(0)=0, g(t)=1 の場合
```

逆に、入力が1 Vから0 Vへ急に戻ったときは、`y(t)` は指数関数的に0 Vへ下がる。

```text
y(t) = y0 exp(-t/tau)    # g(t)=0 の場合
```

ここで `y0` は、下がり始める瞬間の `y(t)` の値である。

この `y(t)` を同軸円筒の空間分布に掛けると、一次遅れ付きの比較式になる。

```text
phi_RC(r,t) = alpha(r) y(t)
```

つまり考え方は次の2段階である。

```text
1. 入力 g(t) から、遅れた入力 y(t) を作る
2. 半径 r の場所では、それに alpha(r) を掛ける
```

`alpha(r)` は場所で決まる係数、`y(t)` は時間で決まる波形である。したがって、中心に近い点も外側に近い点も、時間波形の形は同じで、振幅だけが `alpha(r)` によって変わる。

周波数領域で書くと

```text
Y(omega) / G(omega) = 1 / (1 + j omega tau)
```

である。これは、高い周波数の成分ほど小さくなり、位相も遅れることを表す。ただし、今回のグラフ化では周波数領域で計算したのではなく、時間ステップごとに `y(t)` を更新した。

FEMの時刻刻みに合わせるため、`dt=1 ns` で次の式を使った。

```text
y[n+1] = (y[n] + (dt/tau) g[n+1]) / (1 + dt/tau)
```

これは連続式

```text
tau dy/dt + y = g(t)
```

を時間刻み `dt` で計算できる形にしたものである。初期値は `y[0]=0 V` とした。

### 手書きメモの途中式からの整理

手書きメモでは、まず電場を半径方向成分で

```text
E_r(r,t) = - dphi(r,t)/dr
```

と置いている。静的な同軸円筒解を使うと、電位は

```text
phi(r,t) = g(t) ln(b/r) / ln(b/a)
```

である。これを半径 `r` で微分すると

```text
dphi/dr = - g(t) / (r ln(b/a))
```

なので、電場は

```text
E_r(r,t) = g(t) / (r ln(b/a))
```

となる。メモ上部の

```text
E = - dphi/dr = g(t) / (r ln(b/a))
```

はこの式に対応している。

ここで入力電圧 `g(t)` を周波数成分の重ね合わせとして

```text
g(t) = integral G(f) exp(j 2 pi f t) df
```

と書くと、同軸円筒の電位も同じ係数 `alpha(r)` を掛けた形で

```text
phi(r,t)
  = alpha(r) integral G(f) exp(j 2 pi f t) df

alpha(r)
  = ln(b/r) / ln(b/a)
```

となる。つまり周波数領域では

```text
Phi(r,f) = alpha(r) G(f)
```

である。これがメモ右下の `G(f)` と `U(r,f)` の関係を閉じた形になる。

電場も同様に

```text
E_r(r,t)
  = 1 / (r ln(b/a)) integral G(f) exp(j 2 pi f t) df
```

なので、周波数領域では

```text
E_r(r,f) = G(f) / (r ln(b/a))
```

となる。

一方、メモの一次遅れを入れる場合は、電位そのものではなく、入力電圧を通す補助変数 `y(t)` を

```text
tau dy/dt + y = g(t)
```

で定義する。この式を周波数領域へ移すと

```text
(1 + j 2 pi f tau) Y(f) = G(f)
```

したがって

```text
Y(f) = G(f) / (1 + j 2 pi f tau)
```

である。これを同軸円筒の空間分布に掛ければ

```text
Phi_RC(r,f)
  = alpha(r) G(f) / (1 + j 2 pi f tau)
```

時間領域では

```text
phi_RC(r,t)
  = alpha(r) integral
      G(f) / (1 + j 2 pi f tau)
      exp(j 2 pi f t) df
```

となる。

矩形波を時間領域で直接扱うなら、High区間で `g(t)=V0` として

```text
y(t) = V0 + (y0 - V0) exp(-t/tau)
```

Low区間で `g(t)=0` として

```text
y(t) = y0 exp(-t/tau)
```

を区間ごとにつなげればよい。ここで `y0` は各区間の開始時刻における `y` の値である。

ただし、理想電圧源で中心電極を直接 `g(t)` に固定している場合、上の一次遅れはFEMが必ず従う物理法則ではなく、比較用の近似モデルである。均質媒質では

```text
phi(r,t) = alpha(r) g(t)
```

を代入すると

```text
div(sigma E + epsilon dE/dt) = 0
```

をそのまま満たす。実際、`r E_r = g(t)/ln(b/a)` であり、半径方向に一定なので、円筒座標の発散

```text
(1/r) d(r E_r)/dr
```

は0になる。したがって、この理想化条件では、内部電位の第一候補は一次遅れではなく瞬時同軸解である。

### 今回グラフ化した理論式

今回作成したグラフでは、`model_entyu_1` の中央断面で使った代表半径

```text
r = 100, 500, 1200, 2000, 2400
```

について、次の2種類の理論電位を描いた。

まず、場所で決まる係数を

```text
alpha(r) = ln(b/r) / ln(b/a)
```

とする。ここでは実メッシュに合わせて

```text
a = 25
b = 2500
```

を使った。各半径の係数は次である。

```text
r=100  : alpha=0.698970004
r=500  : alpha=0.349485002
r=1200 : alpha=0.159379381
r=2000 : alpha=0.048455007
r=2400 : alpha=0.008864383
```

瞬時同軸理論のグラフは

```text
phi_instant(r,t) = alpha(r) g(t)
```

で描いた。これは、入力が1 Vの間は `alpha(r)` V、入力が0 Vの間は0 Vになる矩形波である。

一次遅れ比較のグラフは、まず

```text
tau dy/dt + y = g(t)
```

を `tau=10 ns`, `dt=1 ns`, `y[0]=0 V` として離散化し、

```text
y[n+1] = (y[n] + (dt/tau) g[n+1]) / (1 + dt/tau)
```

で `y(t)` を計算した。その後、

```text
phi_RC(r,t) = alpha(r) y(t)
```

で半径ごとの電位を描いた。

したがって、最終的にグラフ化した式は次である。

```text
instant graph:
phi_instant(r,t) = ln(b/r) / ln(b/a) * g(t)

RC comparison graph:
y[n+1] = (y[n] + (dt/tau) g[n+1]) / (1 + dt/tau)
phi_RC(r,t) = ln(b/r) / ln(b/a) * y(t)
```

平均絶対誤差は全時間ステップの絶対誤差を平均した値であり、波形全体の一致度を見る指標である。最大絶対誤差は全時間中で最も大きかった1点の誤差であり、主にパルス切替直後などの最悪差を見る指標である。一方だけでなく両方を確認する。

## 解釈と次の切り分け

理論上、無限長・一様媒質・完全同軸・境界電圧指定の条件では、空間分布は

```text
ln(b/r) / ln(b/a)
```

になるはずである。

そのため、FEM結果がこの分布から大きく外れる場合、主な候補は次のどれかである。

1. 有限長円筒の端部効果
2. 円筒メッシュの四面体分割による異方的な数値誤差
3. 中心電極・外側電極を「体積材料」として固定していることによる境界位置のずれ
4. 要素行列の勾配変換または異方性係数の扱い
5. 時間項 `K_epsilon/dt` と Dirichlet 埋め込みの相互作用

ここで `K_epsilon` は誘電率から組み立てたFEM行列、`K_epsilon/dt` はBackward Eulerで現れる時間項である。Dirichlet埋め込みとは、指定節点の電位を既知値として行列と右辺へ反映する処理を指す。

次の検証としては、同じ半径・高さで以下を行うとよい。

```text
1. 定常解析 dt=0 で同軸円筒理論との半径分布を比較
2. 高さを長くして端部効果が減るか確認
3. 半径方向分割と周方向分割を増やして収束性を見る
4. 2D軸対称または1D半径方向の簡易モデルと比較する
```

特に、まず `dt=0` の定常解析で

```text
phi(r) = ln(b/r) / ln(b/a)
```

に近づくかを見るのが重要である。ここで合わない場合、時間応答以前に空間離散化または行列組立側を疑うべきである。

## `model_entyu` へ適用する際の設定

`models/model_entyu` では、材料の役割を次のように定義する。

```text
material 1 : パルスを印加する中心電極
material 2 : 電位を未知量として解く媒質
material 3 : 0 V に固定する外側電極
```

したがって、`pulse.dat` の対象は材料1とし、`tmate.dat` では材料3だけを0 Vに固定する。材料2を `pulse.dat` または `tmate.dat` で指定すると、媒質全体がDirichlet固定され、媒質内部の電位分布を検証できなくなる。

Dirichlet固定とは、対象節点の電位をソルバーに求めさせず、指定値へ強制する境界条件である。材料1は時刻ごとに0 Vまたは1 Vへ強制し、材料3は常に0 Vへ強制する。材料2だけが、周囲の条件から電位を計算される領域になる。

今回の過渡解析条件は、上記の理論比較条件に合わせて次とする。

```text
material 1 pulse : 0 V / 1 V
high             : 25 ns
low              : 25 ns
period           : 50 ns
dt               : 1 ns
nstep            : 150
material 3       : 0 V fixed
```

矩形波は入力の不連続点で高周波成分を含む。実験との比較段階では、パルス発生器で測定した立上り時間と立下り時間を `t_rise`, `t_fall` に設定する。理論・実装の切り分け段階では、まず0 nsの理想矩形波を用いる。

### `model_entyu` の物性に対応する緩和時間

本文の例では `epsilon_r=20`、`epsilon=1.770838e-10 F/m` を使用したが、現在の `model_entyu` の材料2は次の異方性物性である。

```text
sigma_x = sigma_y = 1.0e-2 S/m
sigma_z             = 8.0e-3 S/m
epsilon_x = epsilon_y = epsilon_z = 1.0e-10 F/m
```

このとき方向別の代表緩和時間は次となる。

```text
tau_x = tau_y = 10.0 ns
tau_z         = 12.5 ns
```

よって、`model_entyu` の結果を一次遅れ近似と比較する場合は、本文の17.708 nsをそのまま使わず、半径方向比較ではまず10 nsを使う。ただし、次節の理由により、理想電圧境界下の内部電位を必ず一次遅れとみなしてはならない。

### 理想電圧境界と `tau` の解釈

空間的に一様な `sigma`, `epsilon` に対して電極電位をDirichlet条件で強制すると、同軸円筒の調和関数

```text
phi(r,t) = g(t) * ln(b/r) / ln(b/a)
```

は時間依存支配式も満たす。このため、理想電圧源・一様媒質という条件では、空間分布は入力 `g(t)` にほぼ瞬時に追従し得る。`tau=epsilon/sigma` は自由電荷の緩和を表す重要な尺度だが、各内部節点の電位が必ず時定数 `tau` の一次遅れになることを意味しない。

理由は、入力電圧を理想的な境界値として直接与える場合、`alpha(r) g(t)` 自体が各時刻で空間方程式を満たせるためである。外部抵抗や電極容量を含む実回路では電極電圧そのものが遅れることがあるが、このモデルでは `g(t)` を電極へ強制しているため、その回路遅れは含まれない。

したがって比較の優先順位は次とする。

```text
第一基準 : 瞬時同軸理論 alpha(r) * g(t)
補助基準 : tau_x = 10 ns の一次遅れ同軸近似
```

FEMだけに時間遅れや残留電位が現れた場合は、直ちに材料緩和と解釈せず、初期条件、有限長端部、異方性、材料境界、時間離散化、Dirichlet条件の埋め込みを切り分ける。

### 推奨する検証順序

1. パルスを外し、材料1を1 V、材料3を0 Vとした定常解析で中央断面の `ln(b/r)` 分布を確認する。
2. 同じ半径について高さ方向にも比較し、中央部と端部の差から有限長端部効果を確認する。
3. `dt=2 ns`, `1 ns`, `0.5 ns` で時間刻み収束を確認する。
4. 25 ns High / 25 ns Lowを3周期計算し、瞬時理論と一次遅れ理論の両方に対する誤差を出す。
5. 実験比較では有限の立上り・立下り時間、発生器出力抵抗、接触抵抗、寄生容量を順に追加する。

比較点は固定電極上ではなく材料2内部に置く。円柱高さ中央で、中心電極近傍、中間半径、外側電極近傍の少なくとも3点を選び、各点について平均絶対誤差、最大絶対誤差、High中の平均値、Low終端の残留値を記録する。

## `model_entyu` 過渡解析結果

上記設定で `dt=1 ns`, `nstep=150` の3周期解析を実行した。使用した境界条件は次のとおりである。

```text
material 1 : 0/1 V, 25 ns High / 25 ns Low
material 2 : 自由節点
material 3 : 0 V固定
```

解析は150 stepを完走した。各ステップのICCGは主に78～80反復で収束し、相対残差はおおむね `1e-10` 未満だった。解析サマリでは、材料1のパルス対象節点数は1057、材料3の固定条件は1エントリとして確認できた。

ICCGは大規模な連立一次方程式を反復的に解く手法である。「78～80反復」は各時刻の解を得るまでの反復回数を表す。相対残差は、現在の解が連立方程式をどの程度満たしていないかを正規化した値で、ここでは `1e-10` 未満なので線形方程式は十分小さい誤差まで解かれている。ただし、ソルバーの収束は物理モデルの妥当性を保証するものではない。

材料3の「1エントリ」は `tmate.dat` に書かれた材料指定が1件という意味であり、固定節点が1個という意味ではない。その1件から、材料3に属する複数節点が0 V固定される。

### 実メッシュの中央断面

`z=750` の中央断面を調べると、正のx軸上では次の境界になっている。

```text
中心電極固定節点 : r = 0, 25
媒質内部節点     : r = 100, 200, ..., 2400
外側0 V節点      : r = 2500, 2525
```

したがって、比較用の代表境界半径としてメッシュ座標値 `a=25`, `b=2500` を用いた。ただし、高さは1500であり、半径方向ギャップ `b-a=2475` より短い。この形状は無限長同軸円筒近似から大きく外れるため、端面境界の影響を無視できない。また、メッシュヘッダの単位値と座標のSI換算は別途確認が必要である。

ここで使う25、2500、1500は、単位換算前のメッシュ座標値である。対数係数 `alpha(r)` の計算では長さの比だけを使うため、この段階では単位が未確定でも計算できる。一方、電場 `[V/m]`、電流 `[A]`、抵抗 `[ohm]` を現実と比較する前には、1メッシュ座標が何mかを確定する必要がある。

### 中央断面の代表点

比較には次の材料2内部節点を用いた。

```text
r=500  : node 181254
r=1200 : node 180954
r=2000 : node 180733
```

`a=25`, `b=2500` とした瞬時同軸理論の係数は次となる。

```text
r=500  : alpha=0.349485002
r=1200 : alpha=0.159379381
r=2000 : alpha=0.048455007
```

3周期目のHigh終端直前であるstep 124では、FEM値は次となった。

1周期は50 stepで、各周期のstep 1～24相当がHigh、step 25でLowへ切り替わる実装になっている。step 124は3周期目でLowへ切り替わる1 step前なので、High期間の終端値として採用した。

```text
                 r=500      r=1200     r=2000
instant theory   0.349485    0.159379   0.048455 V
FEM              0.280130    0.117090   0.028630 V
```

FEMは全点で無限長同軸理論より低く、外側ほど相対差が大きい。これは単一の時間遅れ係数では説明しにくく、有限長端部、端面の0 V境界、電極と媒質の離散境界位置などによって空間分布そのものが変わっている可能性が高い。

### 瞬時理論と一次遅れ理論の誤差

150 step全体について、瞬時同軸理論と `tau=10 ns` のBackward Euler一次遅れ理論を比較した。

表中の `MAE` は平均絶対誤差、`max error` は最大絶対誤差である。`instant` は `alpha(r) g(t)`、`RC` は `alpha(r) y(t)` を比較対象にしたことを表す。

```text
         MAE instant   MAE RC      max error instant   max error RC
r=500    0.055524 V    0.091270 V  0.326453 V          0.318065 V
r=1200   0.029855 V    0.042101 V  0.149749 V          0.143845 V
r=2000   0.012042 V    0.013831 V  0.046099 V          0.042938 V
```

最大誤差だけでは一次遅れ側がわずかに小さい点もあるが、全期間の平均絶対誤差は3点すべてで瞬時理論の方が小さい。これは、理想電圧境界下の電位を単純な局所一次遅れで表すべきではないという解釈と整合する。

1周期目では初期条件の影響が大きく、step 25の立下り直後に次の負電位が生じた。

```text
r=500  : -0.032607 V
r=1200 : -0.013665 V
r=2000 : -0.003360 V
```

一方、3周期目のstep 125ではそれぞれ `0.000175 V`, `0.000031 V`, `-0.000015 V` まで小さくなった。したがって、初回周期だけで物理的時定数を推定せず、周期定常後の波形を使う必要がある。

周期定常とは、1周期前とほぼ同じ波形が繰り返される状態である。初期値0 Vから始めた直後は、パルスに対する応答と初期状態からの過渡成分が重なる。後半周期では初期状態の影響が小さくなるため、材料や実験との比較に適している。

### この解析からの次の判断

現状の過渡計算は数値的には収束しているが、無限長同軸理論の直接検証としては形状条件が適切でない。次の優先作業は、同じ境界条件で定常解析を実行し、続いて高さを十分長くした検証専用モデルと比較することである。

```text
1. 現形状をdt=0で解き、時間項を除いても同じ空間差が残るか確認する
2. 高さを半径方向ギャップの数倍以上にしたモデルで中央断面を比較する
3. 端面を自然境界にしたケースと0 V境界にしたケースを比較する
4. メッシュ単位をSI物性と整合させる
5. その後に有限立上り時間と外部回路を加えて実験値と比較する
```
