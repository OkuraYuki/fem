# 解析入力ファイルの数値と使用箇所

確認日：2026-11-02。対象はこのディレクトリの **現在の C++ ソース**（`main.cpp`、`electrostatic_analyzer.cpp`、`electrostatic_analyzer.h`）。旧 Fortran 版や既存の実行バイナリの仕様を保証するものではない。

通常は `models/<モデル名>/` の入力を読み、`output/<モデル名>/` に結果を保存する。以下では入力中の節点・要素・材料の番号はすべて **1始まり**。内部処理では0始まりに変換される。

## 1. 計算との対応の全体像

定常解析（`dt <= 0`）：

```text
Kσ φ = F
```

過渡解析（`dt > 0`、後退 Euler 法）：

```text
(Kσ + Kε/dt) φ[n+1] = F + (Kε/dt) φ[n]
```

| 入力 | 主な使用先 |
|---|---|
| 座標・要素接続・材料範囲 | 要素体積、形状関数の勾配、全体行列の組立 |
| σx, σy, σz | 導電率行列 Kσ |
| εx, εy, εz | 誘電率行列 Kε、初期誘電場、過渡の時間項 |
| 固定電位・パルス | 節点の固定値、行列と右辺への境界条件適用 |
| 電流源 | 右辺 F（現在の実装上の換算は後述） |
| dt・nstep・time0 | 時間項、ステップ数、波形を評価する絶対時刻 |
| 回路の R・C | 電極自由度の電流釣り合い、電荷履歴 |
| 電圧差の節点番号 | 結果の記録のみ |

## 2. `in.dat`：メッシュ

読み込み：`read_mesh()`。

```text
節点数 要素数 dummy1 dummy2 unit
n1 n2 n3 n4   ← 要素数組
x y z         ← 節点数組
```

改行位置ではなく数値の順序で読む。要素接続が先、座標が後で、各組にID列は付けない。

| 数値 | 現在の使用方法 |
|---|---|
| 節点数 | 座標・電位配列の大きさ、読み込む座標数 |
| 要素数 | 要素配列の大きさ、読み込む4節点組の数 |
| dummy1, dummy2 | 読み捨て。計算に使わない |
| unit | 保存するが、座標の乗算・除算などには使わない |
| n1〜n4 | 四面体を構成する節点番号。形状と行列の加算先を決める |
| x, y, z | ヤコビ行列 J、勾配 J^(-T)∇N、体積 abs(detJ)/6 の計算 |

`unit=1000` でも自動的に座標を1000で割る処理はない。回路結合時の単位換算は `circuit.dat` の `coordinate_scale_to_m` が担当する。abs(detJ) < 1e-20 の要素は組立をスキップする。

## 3. `sin.dat`：材料・固定境界・電流源

読み込み：`read_material_and_bc()`。

```text
ntblk ntmblk ntmate npt2 nlv
node1 node2 type value    ← 境界条件
start end material_id    ← 材料ブロック
σx σy σz εx εy εz        ← 材料物性
nqt
 element_id Ix Iy Iz     ← 電流源
```

### ヘッダー

| 数値 | 使用方法 |
|---|---|
| ntblk | 境界条件レコード数。ただし本文最初の非空行が数値4列の場合だけ境界節を読む |
| ntmblk | 材料割当レコード数 |
| ntmate | 材料数。物性行の順番が材料番号になる |
| npt2, nlv | ヘッダーから読むだけで、解析には使わない |

### 境界条件 `node1 node2 type value`

| 数値 | 使用方法 |
|---|---|
| node1, node2 | **指定された2節点のみ**に作用する。番号間の全節点や境界面を指定するものではない |
| type = 1 または 4 | 両節点を value [V] に固定する |
| type = 5, value = 0 | 零流束の自然境界。追加荷重は加えない |
| その他の type、type 5 の非零 value | 未対応として停止する |

既に `tmate.dat` または `pulse.dat` で固定された節点を、ここで上書きしない。固定節点が全くない通常解析では節点1を0 Vの基準にする。

### 材料割当 `start end material_id`

start〜end の**両端を含む要素範囲**に材料番号を割り当てる。節点範囲ではない。重複範囲は後の割当が優先される。未割当要素の初期材料は1。

### 材料物性

| 行形式 | 数値の解釈 |
|---|---|
| 6列 | σx σy σz εx εy εz |
| 4列（互換形式） | σx σy σz ro。εは各方向1.0に設定 |
| 5列（互換形式） | σx σy σz ro cv。εは各方向1.0に設定 |
| 8列など | 現実装では非対応。材料レコード不正となる |

σは導電率 [S/m]、εは絶対誘電率 [F/m] として使用する。比誘電率へ真空誘電率を掛ける処理はない。物理単位を整合させるには座標の長さ単位も確認する。

各要素について、例えば x 方向の寄与は次の通り（y,zも同様に加算）：

```text
Kσ[a,b] += volume × σx × (∂Na/∂x)(∂Nb/∂x)
Kε[a,b] += volume × εx × (∂Na/∂x)(∂Nb/∂x)
```

非対角の異方性成分は扱わない。`ro`、`cv` は保存するだけの互換用ダミーで、密度・熱容量による計算は行わない。定常の電位計算にはεの時間項を使わない。

### 電流源 `nqt` と `element_id Ix Iy Iz`

nqt は読むレコード数、element_id は対象要素番号。現在の実装では方向別ベクトルとして積分せず、次の2段階で使う。

```text
読み込み時：対象要素の各節点の source に (Ix + Iy + Iz)/4 を加算
組立時    ：各要素の各節点の F に source[節点] × volume/4 を加算
```

共有節点の source は隣接要素の組立にも使われる。Ix, Iy, Iz の和が同じならこの実装での効果は同じで、符号によって相殺も起こる。入力値をそのまま電極への総電流 [A] と解釈しないこと。回路結合では非零の分布電流源を受け付けない。

## 4. `tmate.dat`：材料ごとの固定電位

読み込み：`read_initial_potential()`。

```text
ninit
material_id value   ← ninit行
```

| 数値 | 使用方法 |
|---|---|
| ninit | 固定材料レコード数 |
| material_id | 対象材料の全要素から、その構成節点を抽出 |
| value | 抽出した全節点の固定電位 [V] |

名前は「初期電位」だが、通常は**解析中も続く固定電位条件**。自由節点の初期電位を任意に指定するファイルではない。同じ節点に複数の指定が及ぶ場合、後の指定で上書きする。パルス対象は後で波形値に更新され、回路対象電極は固定を解除して未知電位として解く。

過渡解析の自由節点は、通常、開始時の境界条件に整合する `Kε φ = 0` の無自由電荷場で初期化する。回路で `initial_state steady` を指定した場合は導電定常状態で初期化する。

## 5. `sina.dat.t`：解析制御（重要）

読み込み：`read_analysis_config()`。**単純な「dt、nstep、time0を1行ずつ」の形式ではない。** 空行と `#` 以降を除いた行位置で、次の旧形式を読む。

```text
0 0 0 0 0 0 0       = flags
150 0 0 0 0 0 0     = nstep, ...
1.0e-9 0.0 0         = dt, time0, istep2
0.0 0.0              = freq, freq-end
...以降は旧形式の設定...
```

| 位置・数値 | 現在の使用方法 |
|---|---|
| 1行目の全フラグ | 数値を読むが、分岐や計算に使わない |
| 2行目の1列目 nstep | 過渡解析の最大ステップ数。0以下なら200に置き換える |
| 2行目の残り | 使用しない。nwave、ifconv、iftime等でも動作は変わらない |
| 3行目の1列目 dt | 秒単位の時間刻み。正なら過渡、0以下なら定常を1回求解 |
| 3行目の2列目 time0 | 開始絶対時刻 [s]。省略時0。過渡の波形・出力時刻に反映 |
| 3行目の3列目 istep2 など | 使用しない |
| 4行目 freq, freq-end | 数値を読むが、周波数解析や波形生成に使わない |
| 5行目以降の全数値 | 読み込んだ行を解析設定へ反映しない |

したがって、`ifmat, mite, ia18`、`berr, berr2`、加速係数、`ddmin`、測定節点数 `ntnod` と節点番号、`nrotmat`、その後の回転・波形関連数値は、現在のソルバー設定を変更しない。測定節点は `voltage_difference.dat` で指定する。

過渡のステップkの時刻は `time0 + k×dt`。パルスがない場合は最大電位変化 < 1e-8 V で早期終了できる。パルスが有効なら指定ステップを実行する。外側の1e-8、線形ソルバーの相対残差許容値（定常1e-8、過渡1e-10）はソース内の定数であり、旧入力の `ddmin` で変更できない。

## 6. `pulse.dat`：時間変化する電圧（任意）

読み込み：`read_pulse_config()`、使用：`evaluate_pulse_voltage()`。

```text
material_id v_low v_high t_rise t_high t_fall t_low [phase]
```

| 数値 | 使用方法 |
|---|---|
| material_id | 波形を適用する材料の構成節点を選ぶ |
| v_low, v_high | Low/High 電位 [V] |
| t_rise | Low→Highの線形上昇時間 [s] |
| t_high | High保持時間 [s] |
| t_fall | High→Lowの線形下降時間 [s] |
| t_low | Low保持時間 [s] |
| phase | 位相の時間シフト [s]。省略時0 |

周期 T は4区間の合計、周期内時刻は `(絶対時刻-phase) mod T`。負の剰余はTを足して補正する。区間時間は非負、合計0なら常にLow。立上り・立下り0で矩形波になる。

通常は固定電位を波形で上書きする。実装は対象節点をここでも固定登録するので、同じ材料が `tmate.dat` に存在すること自体は必須ではない。回路対象電極の場合は電源側電圧となる。Low=0 Vだけでは電源開放にならない。

## 7. `circuit.dat`：電源抵抗・開放・外部容量（任意）

読み込み：`read_circuit_config()`。キーと値で指定する。

| キー | 数値・値の使用方法 |
|---|---|
| electrode_material | 電極材料番号。全構成節点を1つの未知電位にまとめる |
| series_resistance_ohm | 切離し前の抵抗 R [Ω]。有限抵抗は電流 `(Vs−Ve)/R`、idealまたは0は理想電圧固定、openは開放 |
| disconnect_time_s | 切離し絶対時刻 [s]。neverは切離しなし。time0より後、dtの格子上に指定 |
| off_resistance_ohm | 切離し後に0 Vへ接続する抵抗 [Ω]。ideal/0は接地固定、openは外部経路なし。切離す場合は必須 |
| external_capacitance_F | 電極と0 V間の追加容量 C [F]。時間項にC/dtを加える。省略時0 |
| coordinate_scale_to_m | 入力座標1単位に対応する長さ [m]。正の数。組立済みKσとKεにこの係数を掛ける |
| initial_state | steadyは導電定常場、charge_freeは無自由電荷の初期誘電場 |

必須キーは electrode_material、series_resistance_ohm、disconnect_time_s、coordinate_scale_to_m、initial_state。対象電極には `pulse.dat` の対応レコードがちょうど1つ必要。過渡解析のみ対応し、電極外の明示的な0 V基準が必要。

切替時刻では電位を保持し、その次の時間区間から切離し後の条件で積分する。追加容量はFEMの誘電容量とは別であり、FEMの容量はεから既に計算される。詳細は [electrical_circuit.md](electrical_circuit.md)。

## 8. `voltage_difference.dat`：測定節点（任意）

```text
node_a node_b [label]
```

2つの数値は元メッシュの節点番号。`V(node_b) − V(node_a)` を記録するために使用し、解析の境界条件や解には影響しない。範囲外の番号は無視される。labelは表示名で、省略可能。

## 9. `symmetry.dat` とその他のファイル

`symmetry.dat` の対応指定は `axis z` のみ。数値設定はない。同一XY座標の節点の電位自由度を統合する。高さ方向の材料・固定条件・電流源の整合性を検査する。σzを消去する指定ではなく、節点電位を拘束する指定である。

`models.dat`（`pulse_models.dat` など別名も可）は1行1モデル名の実行一覧。数値の解析パラメータを指定するファイルではない。

モデル内の `tetra.dat`、`in2d.dat`、`sin2d.dat` 等は、現在の `main.cpp` の解析入力としては読まない。出力側の `tempa.dat*` や `analysis_summary.txt` も解析入力として読まない。

## 10. 実例：`model_entyu_1`

| ファイル・数値 | このモデルでの意味 |
|---|---|
| in.dat：363759, 2095200, 0, 0, 1000 | 363759節点、2095200要素。2つの0とunit=1000は計算に使わない |
| sin.dat：160, 450, 3, 2409, 151 | 境界160件、材料割当450件、材料3種。2409と151は未使用 |
| 材料1・3：σ=5.8e7、ε=8.9e-12（各方向） | 電極材料の導電率・誘電率 |
| 材料2：σ=(0.01, 0.01, 0.008)、ε=(1e-10, 1e-10, 1e-10) | 媒質の方向別物性。XY方向のε/σ=10 ns、Z方向は12.5 ns |
| tmate.dat：1、その次が 3 0 | 固定材料1件、材料3の構成節点を0 Vに固定 |
| pulse.dat：1 0 1 0 25e-9 0 175e-9 0 | 材料1を0〜1 Vで駆動。周期200 ns、最初の25 nsがHigh |
| sina.dat.t：150、1e-9、0 | 最大150ステップ、dt=1 ns、time0=0。終了予定時刻150 ns |
| voltage_difference.dat：180676 181561 | V(181561)−V(180676)を記録 |

このモデルの `sina.dat.t` に書かれた旧測定節点5個や `ddmin` は使われない。`symmetry.dat` があるため同じXY座標の節点は同電位に拘束される。

## 実装の参照先

- [main.cpp](../src/main.cpp)：入力ファイルの選択・読み込み順序。
- [electrostatic_analyzer.cpp](../src/electrostatic_analyzer.cpp)：`read_mesh`、`read_material_and_bc`、`read_initial_potential`、`read_analysis_config`、各任意設定のread関数。
- 同ファイルの `assemble_global_matrix`：座標・物性・電流源の数値利用。
- 同ファイルの `solve`、`prepare_reduced_system`、`add_circuit_terms`：初期状態、時間積分、電位拘束、回路結合。

既存README等の「物性8列」「dt/nstep/time0の3行形式」と異なる箇所は、本書では現在のコードの処理を優先した。
