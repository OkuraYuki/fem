# 土壌検査装置：電界過渡応答解析と電極・パルス条件の設計計画

作成日：2026-11-06

## 目的と到達点

入力側にパルス電圧を印加し、土壌を介して受信側に現れる電圧から誘電率・導電率を推定する装置を対象とする。依頼事項は「電界過渡応答解析手法の検討」と「電極距離やパルス幅を変えた時の特性解析」である。

到達点は、波形の違いを示すことだけでなく、対象土壌の物性を必要な精度で区別できる電極配置とパルス条件を、解析の適用範囲と実験結果を根拠に提案することである。本書は計画であり、最適距離・パルス幅や装置性能を確定した解析結果ではない。

## 現状と設計へ進む際の不足

- [パルス条件比較](../pulse_study_20261104/report.md)：円柱モデルで振幅、High保持時間、周期、立上り・立下りの9条件を比較済み。ただし、理想電圧源で駆動し、内部節点電位を観測する条件である。実際の受信電極・測定器を接続した出力とは区別する。
- [同軸理論比較](../pulse_theory_comparison_20261106/report.md)：切替時刻と波形形状は理論と整合する一方、代表点の電位に約6.77%の空間差が残る。絶対値を設計判断に用いる前に原因調査とメッシュ収束確認が必要。
- [回路結合の仕様](../../docs/electrical_circuit.md)：有限電源抵抗、追加容量、電源切り離しに対応。ただし単一電極回路が対象で、独立した送信・受信電極それぞれへの回路接続は現行機能の対象外。
- 過去の比較では座標の実寸換算を確定していない。回路結合の参照設定には換算係数があるが、実装置の寸法を示す根拠として流用しない。

## 1. 最初に測定仕様をそろえる

依頼者と以下を確認し、未確定事項は仮定と明記して基準条件を作る。

| 項目 | 決める内容 | 設計への影響 |
|---|---|---|
| 測定対象 | 土壌の種類、含水状態、温度、導電率・比誘電率の範囲 | 解析する物性範囲と校正条件 |
| 要求性能 | 誘電率・導電率の許容誤差、測定時間、対象体積 | 設計案の合否基準 |
| 電極構造 | 本数、形状、径・長さ、挿入深さ、距離の定義、接地・帰還経路 | 解析形状・境界条件 |
| パルス発生器 | 振幅、立上り・立下り時間、High保持時間、繰返し周期、出力抵抗、Low時の接続 | 波形と駆動回路 |
| 受信回路 | どの2端子間の電圧か、入力抵抗・入力容量、帯域、サンプリング間隔、雑音 | 実際に測定できる出力 |
| 接続・接触 | 配線長、シールド、電極と土壌の接触状態 | 寄生成分・再現性 |

特に「電極距離」は中心間距離か表面間隔かを定義する。「パルス幅」は本計画ではHigh保持時間とし、立上り・立下り時間とは別に扱う。最終的に報告する誘電率が、特定周波数の値か、所定帯域での実効値かも定義する。

## 2. 解析手法の適用範囲を判定する

現在の実装は導電率行列と誘電率行列を使う電位の過渡解析で、時間離散式は概ね `(Kσ + Kε/Δt)φ(n+1) = F + Kεφ(n)/Δt` である（[実装](../../src/electrostatic_analyzer.cpp)）。電磁波の飛行時間や反射を解く波動ソルバーではない。

| 測定に利用する現象 | 検討する解析手法 | 次の判断 |
|---|---|---|
| 充電・放電、抵抗と容量による波形変形 | 電気準静的なFEMと外部回路の結合 | 現行ソルバーを基礎に適用条件と必要な回路拡張を確認 |
| 到達時間、反射、伝送路としての伝搬 | 伝送線路モデル、必要なら電磁界の全波解析 | 現行ソルバーとは別のモデルを用意 |

電気準静的近似は、対象内の電磁波の伝搬時間が評価する時間変化に比べ十分短い場合を前提とする。判定にはHigh保持時間だけでなく立上り時間と必要帯域を使う。公式資料：[Wolframの電流解析解説](https://reference.wolfram.com/language/PDEModels/tutorial/Electromagnetics/ElectricCurrents.html.en?source=footer)、[COMSOLの過渡解析手法の比較](https://www.comsol.com/blogs/understanding-the-transient-electromagnetic-excitation-options)。

まず実寸、物性範囲、立上り時間をそろえ、上記を判定する。適用範囲が未確定のまま現行FEMの応答を「伝搬遅延」と解釈しない。

## 3. 小さな基準モデルで物性を識別できるか確認する

最初は均一・等方・物性一定の土壌と単純な電極形状を仮定する。入力源の抵抗、受信側の負荷抵抗と入力容量、電圧の基準端子を含める。独立した受信電極が必要な場合は、複数電極回路への拡張または外部回路ソルバーとの結合を検討する。

基準物性に対して、誘電率だけを変更、導電率だけを変更、両方を変更した波形を比較する。波形全体と、振幅・充放電時間・所定時刻の電圧などの特徴量について、2つの物性が異なる変化を与えるか調べる。

一様媒質の単純な抵抗・容量モデルでは、同じ幾何係数 k を使って `G = σk`、`C = εk` と書ける。この条件での自然放電の時定数は `C/G = ε/σ` であり、時定数一つだけでは両物性を個別に決定できない。また、幾何係数が相殺するため、距離を変えれば必ずこの時定数が変わるわけでもない。これは基準モデルの式から得られる設計上の注意であり、受信負荷や寄生成分を含む一般構造の結果ではない。

識別が難しい場合は、複数の観測時刻・パルス幅、既知負荷の切替、入力電流の追加測定などを候補にする。既知の物性を設定して波形を生成し、そこから誘電率・導電率を同時推定して元に戻るか確認する。雑音を加えた場合の推定誤差まで評価し、電圧だけで測定できる条件を判断する。

## 4. 数値精度を確認する

同軸または平行平板の理論・等価回路と比較し、定常値、充放電曲線、電極電流・電荷の整合を確認する。既存円柱モデルの約6.77%の差は原因を特定し、メッシュ細分化に伴う変化を調べる。

時間刻みも段階的に小さくし、受信電圧と推定物性の変化を確認する。刻み幅は最短の立上り・立下り・回路応答を解像できるよう決める。開始前に十分Lowを保持し、初期条件由来の応答とパルスへの応答を区別する。数値誤差の許容値は装置の要求精度から割り当てる。

## 5. 電極距離・パルス幅の特性解析を行う

絶対寸法と使用可能なパルス範囲が未確定のため、以下は条件の組み方であり、製作値の推奨ではない。

1. 基準の電極形状・回路を固定し、土壌物性の低・中・高の組合せを計算する。
2. 電極距離だけを変更する。電極径・挿入深さ、物性、入力・受信回路を共通にする。
3. High保持時間だけを変更する。振幅と立上り・立下り時間を共通にし、Low期間を十分確保する。周期を固定する比較と、Low期間を固定する比較を混同しない。
4. 有望な範囲で距離×High保持時間の組合せを比較する。各形状で同等のメッシュ精度を保つ。
5. 候補を絞って、立上り時間、受信容量、接触状態、配線・温度などの変動への頑健性を評価する。

距離とHigh保持時間はそれぞれまず3〜5水準程度で粗く探索し、物性の組合せも含め計算量を見積もってから詳細化する。小さなモデルで探索し、最終候補を実形状で確認する。

評価は、受信電圧の大きさだけでなく、物性に対する変化量、雑音に対する区別のしやすさ、2物性の同時推定誤差、測定時間、電源電流・エネルギー、検査対象体積、接触条件によるばらつきを使う。波形の平均値や実効値だけでは設計案の優劣を決めない。

## 6. 実測で照合し設計案を提示する

物性が別手段で確認された基準試料などで、入力端と受信端の波形を測る。電源出力抵抗、入力容量、配線、接触条件を記録し、解析との差を調べる。校正に使った条件とは別の試料・距離条件で推定精度を検証する。

そのうえで、電極配置とパルス条件の候補を2〜3案に絞り、推定誤差、適用する土壌範囲、測定時間、寸法上の制約を併記して選定する。含水率等への換算は、誘電率・導電率の推定とは別に校正が必要な課題として扱う。

## 着手順序と成果物

| 順序 | 作業 | 成果物・次へ進む条件 |
|---|---|---|
| 1 | 装置の概略図と測定仕様を整理 | 電極・帰還経路・受信回路・実寸・要求精度の基準表 |
| 2 | 充放電方式か伝搬方式かを判定 | 解析手法の選定理由と適用範囲 |
| 3 | 小規模な回路付き基準モデルを作成 | 誘電率と導電率を区別できる見通し。困難なら測定条件を見直す |
| 4 | 理論比較・メッシュ・時間刻みを検証 | 要求精度に応じた数値誤差の確認 |
| 5 | 物性・距離・High保持時間を比較 | 条件一覧、受信波形、推定誤差による設計候補 |
| 6 | 試作・実測照合・独立条件で検証 | 最終推奨条件、校正方法、適用範囲 |

直近に行うべきことは、電極と測定回路の基準仕様を置き、物性の変更が受信電圧にどう現れるかを小さなモデルで確認することである。既存の大規模円柱モデルを使った距離・パルス幅の総当たりは、その確認と精度検証を経てから行う。
