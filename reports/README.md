## 追加・更新のルール

1. 報告書を保存したら、この一覧に作成日・相対リンク・説明を追加します。
2. 説明には対象モデル、調査目的、比較内容などを1〜2文で記載します。
3. 既存報告書の更新時は該当行の説明を見直し、必要なら「更新：YYYY-MM-DD」を説明に追記します。同じ報告書を重複登録しません。
4. 作成日が確認できる報告書は新しい順に並べます。不明な日付は推測せず「不明」と記載します。
5. 本文と図・CSVは同じ解析フォルダで管理し、一覧のために複製・移動しません。
6. 追加したリンクが存在することを確認します。

新規登録の例：

```markdown
| YYYY-MM-DD | [報告書の名前](../output/解析名_YYYYMMDD/report.md) | 対象モデルと、何を解析・比較したか。 |
```

一覧はエージェントが報告書の作成・更新と同時に保守します。
手作業や外部ツールだけでファイルを追加した場合は、自動登録されないため、この一覧にも追記してください。
